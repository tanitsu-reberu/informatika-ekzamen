# Информатика: Экзамен

Современная веб-игра для подготовки к экзамену по информатике по 11 билетам.

## Что есть внутри

- Главная страница с карточками всех 11 билетов.
- Прогресс по каждому билету.
- Режим тренировки по выбранному билету.
- Режим экзамена на 10 случайных вопросов.
- Разбор ошибок и кнопка повторения ошибок.
- Очки, streak, достижения и статистика.
- LocalStorage для сохранения прогресса.
- Три интерактивных тренажёра:
  - таблица истинности;
  - перевод числа из пятеричной системы;
  - простой SQL-тренажёр.

## Запуск

Из-за символа `&` в родительском пути `экзамен&информатика` обычные `npm run ...` на Windows могут ломаться. Поэтому добавлены стабильные `.cmd`-запускатели.

### Dev-сервер

```bat
start-dev.cmd
```

Откройте:

```text
http://127.0.0.1:5173
```

### Production build

```bat
build-project.cmd
```

## Деплой

Сайт публикуется на GitHub Pages:

```text
https://tanitsu-reberu.github.io/informatika-ekzamen/
```

После `git push` в `main` GitHub Actions автоматически собирает и выкладывает `dist`.
